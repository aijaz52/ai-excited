Solar Iris is a procedurally rendered image of a luminous magnetic aperture: gold and cyan plasma loops surround a dark iris and converge on a bright ignition point.

The entry is generated by `main.ts` using only the Node.js standard library. Deterministic geometry and grain, additive radiance, and rendering at twice the final resolution produce a 1024 × 1024 PNG. The renderer implements PNG encoding directly and compresses it with `node:zlib`, with no external dependencies.

View the rendered image in [entry.png](entry.png).

## Generate the image

With a Node.js version that supports `--experimental-strip-types` (Node.js 22.6 or later), run:

```sh
node --experimental-strip-types main.ts
```

This writes `entry.png` to the current directory. Set `MAKEFUN_OUTPUT_DIR` to write it elsewhere:

```sh
MAKEFUN_OUTPUT_DIR=./output node --experimental-strip-types main.ts
```

You can also run `node gen-preview.mjs` to regenerate `entry.png` in the repository directory.
